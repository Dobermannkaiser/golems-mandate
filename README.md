# Golem's Mandate

Golem's Mandate é um jogo narrativo de gerenciamento de vila desenvolvido com Godot 4.

## Sobre o projeto

O jogador administra uma vila, organiza seu Conselho, desenvolve construções e toma decisões que afetam a economia, os relacionamentos e o futuro da comunidade.

O projeto inclui sistemas de:

* gerenciamento e evolução da vila;
* Conselho com personagens procedurais;
* construções por fila;
* economia e avaliações sazonais;
* acontecimentos e consequências encadeadas;
* relacionamentos, afinidades e conflitos;
* recrutamento e progressão;
* previsões e ferramentas internas de teste.

## Versão disponível
