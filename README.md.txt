# Golem's Mandate

Jogo narrativo de administração e desenvolvimento de vila criado em Godot 4.

Esta é a versão estável final da Parte 3: v3.11.5.

## Principais sistemas

- administração e evolução da vila;
- Conselho com personagens procedurais;
- construções por fila;
- economia e avaliações sazonais;
- acontecimentos com consequências encadeadas;
- relacionamentos, afinidades e conflitos;
- recrutamento e progressão de personagens;
- previsões e ferramentas internas de teste.

## Como abrir

1. Instale uma versão compatível do Godot 4.
2. Abra o Godot Project Manager.
3. Selecione `Import`.
4. Escolha o arquivo `project.godot`.
5. Importe e abra o projeto.
